# Automação de Fechamento de Vendas — ERP

## Sobre o projeto

Projeto de automação desenvolvido em Python para otimizar o processo periódico de fechamento de vendas de uma empresa do setor de alimentação.

A solução foi desenvolvida para reduzir o trabalho manual envolvido na extração, tratamento, consolidação e atualização das informações utilizadas no processo.

## Problema

O processo era realizado manualmente, envolvendo:

- extração de relatórios;
- tratamento e organização dos dados;
- aplicação de regras de negócio;
- consolidação das informações;
- atualização dos arquivos utilizados no fechamento.

Esse processo consumia uma semana de trabalho.

## Solução

Desenvolvi uma automação integrada ao ERP utilizado pela empresa para:

- acessar o sistema;
- extrair os relatórios necessários;
- processar e organizar os dados;
- aplicar as regras de negócio;
- atualizar as informações utilizadas no fechamento;
- gerar os resultados necessários para o processo.

## Tecnologias

- Python
- Playwright
- OpenPyXL
- Excel
- LibreOffice
- Windows Task Scheduler

## Resultados

O processo, que anteriormente consumia uma semana de trabalho, passou a ser executado automaticamente em aproximadamente 5 minutos.

Após a implementação inicial, também foram realizados ajustes para melhorar a confiabilidade da execução, tratar falhas e adaptar a automação a novos cenários.

## Minha atuação

Fui responsável por compreender o processo de negócio, levantar as regras utilizadas, desenvolver a automação, realizar testes, identificar problemas e implementar os ajustes necessários para seu funcionamento.

O desenvolvimento também envolveu a análise do processo real e a transformação das regras de negócio em lógica automatizada.
